### DataTypes 
In java datatypes specify the type of values a variable can hold.They define the size,range and nature of data stored in memory.

Why are datatypes required?

Java is statically typed this means every variable in java must declare its datatype before use.


Java datatypes are declared into two main categories
  - Primitive: int, byte, char, long, boolean, short, float, double
  - Non-Primitive: Strings, Arrays, Classes, Interfaces, Objects
