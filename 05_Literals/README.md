### Literals in java

    A literal is a fixed,constant value written directly in your  source code as opposed to a variable or result of an expression.
    int x = 5; the 5 is a literal
                 (or)
    Literal are fixed values that are written directly in your java program.They represent constant values assigned to variables 
    or used in expressions.

### Types of Literals

    ```
    . Integer Literals
    . Floating-Point Literals
    . Character Literals
    . String Literals
    . Boolean Literals
    . Null Literals

    ``` 
Note:
    . Literal type must be compatible with the variables declared type(eg you need the L suffix for a value too large to fit).
    . Underscores in numeric literals cant be at start/end of the number or next to a decimal point they are purely visual
      separators for the compiler.
